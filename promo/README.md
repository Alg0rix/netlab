# netlab showreel

An 88-second motion-graphics product video for netlab: what it is, how it works, and a live demo of the real app. Every frame is generated by code: the motion design is a deterministic canvas composition, the demo footage is recorded from the running app, and the soundtrack is synthesised from scratch.

| Time | Scene | What the viewer learns |
|---|---|---|
| 0:00 | **A single packet** grows into a living network | the subject is networking |
| 0:06 | **The problem**: servers, hypervisors, licenses, setup time | why labs are painful |
| 0:12 | **Reveal**: netlab in a browser tab | the one-line pitch |
| 0:20 | **How it works**: Rust/WASM fabric + real IOS/RouterOS/x86 on one virtual wire, all stored locally | the architecture |
| 0:32 | **Demo** (real footage, 5 chapters): place devices → cable → ping → simulation mode → capture & `.pcap` | how to use it |
| 1:10 | **Features** + “0 servers · 0 installs · 100% in your browser” | the breadth |
| 1:18 | **Outro**: `make wasm && make serve` → `localhost:8471` | how to start |

## Files

| File | Role |
|---|---|
| `timeline.js` | Single source of truth: scene times, demo segments/speeds, camera moves, callouts, sound cues (120 BPM, so every cut lands on a bar) |
| `reel.html` | The composition. Open it in a browser for an interactive preview (Space = play/pause, ←/→ = ±2 s, `?t=42` to start at a time) |
| `capture/record.js` | Drives the real app with Playwright and records hi-DPI screencast frames plus a log of the cursor path and clicks |
| `music.mjs` | Synthesises the soundtrack (kick, bass, pads, arps, risers, impacts, whooshes, UI clicks synced to the recorded clicks) |
| `render.mjs` | Renders `reel.html` frame by frame in headless Chromium and encodes with ffmpeg |

## Rebuild

Requires Node 18+, Playwright with Chromium, and ffmpeg.

```sh
make wasm && make serve &                   # the app on :8471 (needed only for recording)
node promo/capture/record.js                # → promo/capture/out/{build,sim,cap}/
node promo/music.mjs                        # → promo/build/music.wav
node promo/render.mjs                       # → promo/build/netlab-showreel.mp4 (1080p60)

node promo/render.mjs --stills 14,58        # spot-check frames as PNGs
node promo/render.mjs --from 32 --to 40     # render a range for review
```

If you re-record, the clip timings shift slightly. Check the `marks` printed by `record.js` against `SEGMENTS`, `CAMERA` and `CALLOUTS` in `timeline.js`.
